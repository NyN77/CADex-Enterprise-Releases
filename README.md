# CADex Enterprise — releases

Установщики и пакеты обновления CADex Enterprise для Windows и КОМПАС-3D.

Обновления переносятся вручную на флешке и устанавливаются на ПК закрытой локальной сети. Приложение не обращается к GitHub и не загружает обновления автоматически.

Первый установщик пока не опубликован. Репозиторий подготовлен для будущих бинарных выпусков.

Исходный код приложения закрыт и в этом репозитории не размещается. Автоматические архивы «Source code» GitHub содержат только этот информационный README, а не код приложения. Установщики следует скачивать из assets конкретного релиза.
