# CADex Enterprise — релизы

[Скачать CADex Enterprise 0.1.0 — предварительная версия](https://github.com/NyN77/CADex-Enterprise-Releases/releases/tag/v0.1.0).

Полный офлайн-установщик Windows x64 со встроенным .NET переносится на флешке. Приложение не обращается к GitHub и не загружает обновления автоматически.

Доступны интерфейс, проекты, файлы, чат и журнал. Локальный ИИ и CAD-исполнитель пока не подключены. Приёмка на чистом закрытом ПК ещё предстоит; установщик пока без цифровой подписи.

Исходный код приложения закрыт. Этот репозиторий содержит только README и бинарные ресурсы релизов. Автоматические архивы GitHub Source code содержат только README. Для установки скачивайте EXE из релиза.
